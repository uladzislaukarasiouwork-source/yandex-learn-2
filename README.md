# Предсказание стоимости поездки в сервисе такси

Модель машинного обучения для прогнозирования стоимости поездки на основе исторических данных такси.

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте окружение и установите зависимости:

pip install -r requirements.txt

## Использование

Проект разделён на модули, которые можно запускать отдельно:

- **Предобработка данных:** `python src/data.py`
- **Создание признаков:** `python src/features.py`
- **Обучение модели:** `python src/model.py`
- **Полный пайплайн:** `python src/main.py` (запускает все этапы последовательно)
